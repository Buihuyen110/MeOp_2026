# Лабораторная работа №1
## Решение задачи линейного программирования двухфазным симплекс-методом

## Постановка задачи

Необходимо решить задачу линейного программирования:

$$
F = x_1 + 2x_2 + 3x_3 + x_4 \rightarrow \min
$$

при ограничениях:

$$
\begin{aligned}
x_1 + 2x_2 + x_3 &\leq 7, \\
x_2 + x_3 + x_4 &= 6, \\
x_1 + x_4 &\geq 2, \\
x_1, x_2, x_3, x_4 &\geq 0.
\end{aligned}
$$

Для решения задачи используется программная реализация симплекс-метода без применения готовых оптимизационных библиотек и solver-функций.

## Используемый метод

В программе реализован двухфазный симплекс-метод.

Из-за наличия ограничений типов `=` и `>=` невозможно сразу получить удобный начальный базис, поэтому вводятся дополнительные и искусственные переменные.

После преобразования система имеет вид:

$$
x_1 + 2x_2 + x_3 + x_5 = 7
$$

$$
x_2 + x_3 + x_4 + x_7 = 6
$$

$$
x_1 + x_4 - x_6 + x_8 = 2
$$

Здесь:

- `x1–x4` — переменные исходной задачи;
- `x5` — добавочная переменная;
- `x6` — избыточная переменная;
- `x7`, `x8` — искусственные переменные.

Решение выполняется в две фазы.

### Фаза I

На первой фазе решается вспомогательная задача с искусственными переменными.

Цель первой фазы — получить допустимый базис для исходной задачи и исключить искусственные переменные.

Если минимальное значение вспомогательной функции равно

$$
Q_{\min} = 0,
$$

то исходная задача имеет допустимое решение.

### Фаза II

После удаления искусственных переменных восстанавливается исходная целевая функция:

$$
F = x_1 + 2x_2 + 3x_3 + x_4 \rightarrow \min.
$$

Далее выполняются симплекс-итерации до получения оптимального решения.

## Что делает программа

Программа автоматически выполняет следующие действия:

1. Создаёт начальную симплекс-таблицу.
2. Формирует целевую строку для первой фазы.
3. Выбирает переменную, которая входит в базис.
4. Выбирает переменную, которая выходит из базиса.
5. Определяет разрешающий элемент.
6. Выполняет преобразование симплекс-таблицы.
7. Повторяет итерации до достижения оптимума.
8. Проверяет значение вспомогательной функции.
9. Удаляет искусственные переменные.
10. Переходит ко второй фазе.
11. Решает исходную задачу.
12. Выводит найденные значения переменных.
13. Вычисляет минимальное значение целевой функции.
14. Проверяет выполнение исходных ограничений.

Для вычислений используется класс `Fraction`, что позволяет работать с точными дробными значениями и избежать ошибок округления.

## Основные функции программы

### `format_number(value)`

Форматирует значения перед выводом в симплекс-таблицу.

Если значение является целым числом, оно выводится как целое число. Если значение является дробным, оно выводится в виде точной дроби.

### `print_tableau(...)`

Выводит текущую симплекс-таблицу.

Функция отображает:

- базисные переменные;
- коэффициенты при переменных;
- правые части ограничений;
- строку целевой функции.

Это позволяет проследить все итерации алгоритма.

### `choose_pivot_column(...)`

Выбирает разрешающий столбец.

Он определяет переменную, которая должна войти в базис, на основании коэффициентов строки целевой функции.

### `choose_pivot_row(...)`

Выбирает разрешающую строку.

Используется правило минимального положительного отношения:

$$
\frac{b_i}{a_{ij}}.
$$

Переменная, соответствующая выбранной строке, выходит из базиса.

### `pivot(...)`

Выполняет основное симплекс-преобразование.

Функция:

- делит разрешающую строку на разрешающий элемент;
- обнуляет остальные элементы разрешающего столбца;
- формирует новую симплекс-таблицу.

### `simplex(...)`

Основная функция симплекс-алгоритма.

Она последовательно:

- выводит текущую таблицу;
- выбирает разрешающий столбец;
- выбирает разрешающую строку;
- выполняет pivot-преобразование;
- обновляет базис;
- проверяет условие окончания алгоритма.

Итерации продолжаются до тех пор, пока оптимальное решение не будет найдено.

### `build_objective_row(...)`

Формирует строку целевой функции с учётом текущего базиса.

Функция используется для корректного вычисления оценок перед запуском симплекс-итераций.

## Результат работы программы

На первой фазе получено:

$$
Q_{\min} = 0.
$$

Следовательно, исходная задача имеет допустимые решения, а искусственные переменные могут быть удалены.

После выполнения второй фазы получено оптимальное решение:

$$
x^* = (0;\ 0;\ 0;\ 6).
$$

Минимальное значение целевой функции:

$$
F_{\min} = 6.
$$

Проверка ограничений:

$$
x_1 + 2x_2 + x_3 = 0 \leq 7
$$

$$
x_2 + x_3 + x_4 = 6
$$

$$
x_1 + x_4 = 6 \geq 2
$$

Таким образом, найденное решение удовлетворяет всем ограничениям задачи.
